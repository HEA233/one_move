# ONE MOVE

Sales tell brands who won. Surveys tell them what people say mattered. ONE MOVE tests the moment in between: if a shopper rejects you, what single change is enough to make them reconsider?

## Start locally

Requirements: Node.js 24.1.0 and npm 11.3.0.

```sh
npm install
npm run dev
```

Open [http://localhost:3000/play](http://localhost:3000/play).

If port 3000 is already in use:

```sh
npm run dev -- --port 3100
```

Then open [http://localhost:3100/play](http://localhost:3100/play).
